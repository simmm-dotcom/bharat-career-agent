# 🇮🇳 Bharat Career Agent

An AI-powered career guidance platform designed to help Indian students discover career paths, identify skill gaps, analyze resumes, build personalized learning roadmaps, and prepare for internships.

## 🚀 Project Overview

Many students know the career they want but are unsure about:

- What skills they need
- What they should learn first
- Which projects they should build
- How to prepare for internships
- How to improve their resume
- How to create a structured career roadmap

Bharat Career Agent addresses this problem using an AI-powered career guidance and action-planning system.

Instead of only answering questions, the Career Action Agent analyzes the student's goal, current skills, experience level, available study time, and target duration to create a structured action plan.

---

## ✨ Features

### 🤖 AI Career Assistant

Students can ask questions about:

- Career paths
- Technical skills
- Internships
- Projects
- Interview preparation
- Higher education
- Learning roadmaps

### 📄 AI Resume Analyzer

Students can upload a PDF resume and receive:

- Resume summary
- Strength analysis
- Skills detected
- Recommended skills
- Suitable career roles
- Project recommendations
- Internship preparation advice
- Resume improvement suggestions

### 🚀 Personalized Career Roadmap

The system creates a roadmap using:

- Education
- Department
- Year of study
- Current skills
- Interests
- Career goal

It generates learning priorities, project ideas, internship preparation guidance, and actionable next steps.

### 🧠 Career Action Agent

The Career Action Agent follows a structured workflow:

1. Understand the career goal
2. Analyze current skills
3. Identify skill gaps
4. Prioritize skills
5. Select practical projects
6. Generate a 12-week action plan
7. Build an internship strategy
8. Define progress checkpoints
9. Recommend immediate actions

The plan also considers the student's available study hours.
